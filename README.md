\# Visual Product Search Engine



\## Setup



\### Create venv



```bash

python -m venv venv

```



\### Activate



```bash

venv\\Scripts\\activate

```



\### Install dependencies



```bash

pip install -r requirements.txt

```



\### Download assets



Download:

\- embeddings

\- indexes

\- dataset



from Google Drive link.



Place them in project root.



\### Run app



```bash

streamlit run streamlit\_app/app.py

```
